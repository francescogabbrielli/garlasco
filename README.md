# I fatti di Garlasco

&Egrave; un'applicazione Amplify Gen 2 + Angular 20 + DynamoDB, per la ricerca e il collegamento di eventi tramite relazioni temporali, spaziali, causa/effetto e altro, legati al caso di omicidio irrisolto di Garlasco.
